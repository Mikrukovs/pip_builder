## Особенности

### Аватары
- **С фото**: Показывается фото из Telegram
- **Без фото**: Цветной круг с инициалами (первая буква имени + фамилии)
- **Цвета**: Автоматически генерируются на основе user ID (каждый пользователь всегда получает один и тот же цвет)

### Стек
- Показывается максимум **5 аватаров**
- Если больше - показывается **+N** для остальных
- Аватары **перекрываются** для компактности

### Статус
- **Зеленая точка** с анимацией пульсации = онлайн
- **Серая точка** + "Оффлайн" = нет подключения к WebSocket

## Технические детали

### Server-side (server.js)
- Новая функция `getUsersInRoom()` - возвращает уникальных пользователей
- Событие `join-project` принимает объект `{ projectId, userInfo }`
- Событие `users-update` отправляет полный список пользователей всем в комнате
- При disconnect автоматически обновляет списки во всех комнатах

### Client-side
- `useCollaboration` hook отправляет `userInfo` при подключении
- Получает событие `users-update` с массивом пользователей
- `CollaboratorsStack` компонент рендерит аватары и дропдаун

### Структура userInfo
```typescript
{
  id: number,
  firstName: string,
  lastName: string | null,
  photoUrl: string | null,
  username: string
}
```
