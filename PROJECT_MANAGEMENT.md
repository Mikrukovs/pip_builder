# Управление проектами

## Что добавлено

### ✅ Меню действий для проектов
Каждый проект теперь имеет меню с тремя точками (⋮) в правом верхнем углу карточки.

**Доступные действия:**
- **Управление доступом** - добавить/удалить участников проекта (для всех)
- **Переместить в папку** - организовать проекты по папкам (только владелец)
- **Удалить проект** - удалить проект навсегда (только владелец)

### 🤝 Управление участниками проекта
Теперь можно добавлять пользователей в проект напрямую, даже если проект не в папке.

**Как это работает:**
1. Нажмите на меню проекта (⋮)
2. Выберите "Управление доступом"
3. Найдите пользователя по имени или username
4. Нажмите на пользователя, чтобы добавить
5. Удаляйте участников кнопкой "Удалить"

**Поиск пользователей:**
- Начните вводить имя или username
- Поиск начинается от 2 символов
- Отображаются только пользователи, которых еще нет в проекте

### 📁 Перемещение проектов
Проекты можно перемещать между папками или убирать из папок.

**Как переместить:**
1. Нажмите на меню проекта (⋮)
2. Выберите "Переместить в папку"
3. Выберите папку назначения или "Без папки"
4. Нажмите "Переместить"

**Важно:**
- Только владелец может перемещать проекты
- Нельзя переместить проект в ту же папку, где он сейчас находится
- Список показывает только ваши папки

### 🗑️ Удаление проектов
Владелец проекта может удалить его в любой момент.

**Как удалить:**
1. Нажмите на меню проекта (⋮)
2. Выберите "Удалить проект"
3. Подтвердите удаление
4. Проект удалится навсегда

**Важно:**
- Только владелец может удалять проекты
- Удаление необратимо
- Все данные проекта будут потеряны

## API Endpoints

### GET /api/projects/[id]/collaborators
Получить список участников проекта

**Права доступа:** Владелец, участник проекта, участник папки

**Ответ:**
```json
{
  "collaborators": [
    {
      "id": 1,
      "userId": 2,
      "role": "editor",
      "createdAt": "2026-02-04T...",
      "user": {
        "id": 2,
        "firstName": "Иван",
        "lastName": "Иванов",
        "username": "ivanov",
        "photoUrl": "https://..."
      }
    }
  ]
}
```

### POST /api/projects/[id]/collaborators
Добавить участника в проект

**Права доступа:** Только владелец проекта

**Тело запроса:**
```json
{
  "userId": 2,
  "role": "editor"
}
```

**Ответ:**
```json
{
  "collaborator": { /* новый участник */ }
}
```

### DELETE /api/projects/[id]/collaborators/[userId]
Удалить участника из проекта

**Права доступа:** Только владелец проекта

**Ответ:**
```json
{
  "success": true
}
```

## Примеры использования

### Сценарий 1: Организация проектов
У вас много проектов на главной странице без папок:
1. Создайте папки для разных категорий ("Клиенты", "Личные", "Тесты")
2. Для каждого проекта откройте меню → "Переместить в папку"
3. Выберите нужную папку
4. Проекты организованы! 🎉

### Сценарий 2: Совместная работа
Нужно дать доступ коллеге к конкретному проекту:
1. Откройте меню проекта → "Управление доступом"
2. Найдите коллегу по username
3. Добавьте его в проект
4. Коллега сразу увидит проект в своем списке "Недавние проекты"
5. Можете работать вместе в real-time! 🤝

### Сценарий 3: Очистка проектов
Хотите удалить старые тестовые проекты:
1. Для каждого проекта откройте меню → "Удалить проект"
2. Подтвердите удаление
3. Проект исчезнет из всех списков

## Известные ограничения

1. Нельзя массово перемещать проекты (только по одному)
2. Поиск пользователей не показывает email (только имя и username)
3. Нельзя изменить роль участника после добавления (только удалить и добавить снова)
